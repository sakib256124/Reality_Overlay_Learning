## Optimization Workflow

```text
Student Data
    -> Quantum-Inspired Optimization
    -> Learning Pattern Analysis
    -> Path Ranking
    -> Best Supervised Learning Strategy
```

The current implementation is quantum-inspired classical optimization. It prepares clean adapter points for future quantum computing or quantum machine learning services without requiring real quantum hardware.

## Knowledge Discovery

`QuantumKnowledgeDiscovery` analyzes behavior signals, knowledge gaps, and research hints to propose hidden concept relationships. These records are draft-only and should be teacher-reviewed before affecting student-facing learning content.
