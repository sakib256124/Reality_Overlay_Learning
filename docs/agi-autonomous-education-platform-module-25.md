## Cognitive Learning System Design

The cognitive layer models:

- Learning speed from recent score patterns and repeated mistakes.
- Memory retention from skill mastery minus mistake pressure.
- Concept difficulty from current skill graph mastery.
- Engagement patterns from AR, tutor, quiz, and research activity.
- Future learning prediction from retention, mastery, and unresolved gaps.
- Skill map through `SkillGraphNode` mastery and prerequisite relationships.

## Database Architecture

Room tables added for Module 25:

- `agi_memory`: lifelong learning event stream.
- `learner_models`: current learner model snapshot.
- `skill_graphs`: learner-specific skill mastery graph.
- `ai_decisions`: AGI decision/audit trail.
- `learning_goals`: active learner goals.
- `future_recommendations`: future guidance generated by AGI planning.
- `knowledge_evolution`: curriculum and knowledge graph evolution proposals.

Cloud collection names should mirror these product concepts:

- `agiMemory`
- `learnerModels`
- `skillGraphs`
- `aiDecisions`
- `learningGoals`
- `futureRecommendations`
- `knowledgeEvolution`
