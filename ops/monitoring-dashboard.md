# ROLA Monitoring Dashboard

## System Health

- Cloud Functions invocation count, error count, p95 latency, cold starts.
- Firestore document reads, writes, deletes, rejected rule evaluations, index build status.
- Storage downloads, bandwidth, failed requests, large-object delivery.

## User Activity

- Daily active learners.
- Learning sessions started and completed.
- Objects scanned.
- Quiz attempts and completion rates.
- Tutor and translation requests.

## AI Performance

- On-device TFLite inference latency.
- Cloud AI route latency.
- Model version adoption.
- Model rollback count.
- Recognition confidence distribution.

## Crash And Performance

- Crash-free users.
- Crash-free sessions.
- ANR rate.
- Startup time.
- AR session frame health.
- Network request latency.

## Release Health

- Current version adoption.
- Staged rollout percentage.
- New crash clusters by version.
- Migration failures.
- Backend deploy errors.
